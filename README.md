# 三体 3D 模拟器 · THREE-BODY 3D SIMULATOR

基于 **Three.js** 的实时三体引力运动模拟器。使用 Fourth-Order Yoshida 辛积分器精确求解三恒星 + 行星的 N 体运动，配合电影化（SpaceX 设计语言）的控制面板，可实时调参、观察混沌系统的演化。

🌐 在线演示：https://threebody-3d.pages.dev/

---

## ✦ 特性

- **真实物理**：牛顿万有引力 + 4 阶 Yoshida 辛积分器，长期能量守恒、数值稳定。
- **四体系统**：3 颗恒星 + 1 颗行星，每体质量、三维初速度均可调。
- **引力软化**：可选 softening，避免近距离奇点导致数值爆炸。
- **碰撞检测**：天体重合时触发碰撞反馈。
- **引力牢笼（球形边界）**：非线性约束力场，防止天体逃逸出视野，含边界/预警半径、场强、阻尼等参数。
- **轨迹绘制**：自定义着色器轨迹，可调长度与颜色，叠加混合发光。
- **质心可视化**：实时显示系统质心位置。
- **电影级后期**：`UnrealBloomPass` 泛光，恒星自发光质感。
- **智能镜头**：
  - 自动缩放（按质心距离取景，拖动时自动暂停，松手 5 秒恢复）
  - 自动旋转（可控速度 / 角度限制）
  - 鼠标跟随（可选，灵敏度 / 范围可调）
  - `OrbitControls` 阻尼拖动，顺滑手感
- **星际尘埃**：近 / 中 / 远三层粒子场，可调密度、漂移、透明度、光照。
- **实时遥测**：系统动能 / 势能 / 总能量 / 角动量 / 牢笼势能 / 最近天体状态。
- **极简 UI**：纯黑背景 + 近白排版，遵循 SpaceX 设计系统（锐利矩形、无圆角、无投影、统一缓动）。

## 🚀 本地运行

环境要求：**Node.js 18+**

```bash
# 安装依赖
npm install

# 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 构建为单文件静态站点（输出 dist/）
npm run build
```

构建产物经 `vite-plugin-singlefile` 内联为单一 HTML，可直接部署到任意静态托管。

## ☁️ 部署

项目已配置 Cloudflare Pages 自动部署（`wrangler.toml`）：

- 构建命令：`npm run build`
- 输出目录：`dist`

推送到 Git 主分支后，Cloudflare Pages 会自动构建并发布。

## 🎮 使用说明

| 操作 | 说明 |
|---|---|
| **开始 / 暂停 / 重置 / 恢复** | 控制模拟运行状态 |
| **质量 / 速度 X·Y·Z** | 设置 4 个天体的初始条件 |
| **引力常数 / 运行速度** | 调节引力强度与仿真倍率（1–50×） |
| **轨迹长度** | 拖尾保留的采样点数（10–5000） |
| **镜头控制** | 自动缩放 / 自动旋转 / 鼠标跟随及各自参数 |
| **引力牢笼系统** | 球形边界约束，可调边界、预警、场强、非线性指数、阻尼 |
| **星际尘埃** | 三层粒子背景密度与光照 |
| **鼠标拖动** | 自由旋转视角（自动缩放在此期间暂停，松手后恢复） |
| **滚轮** | 缩放视角 |

面板右上角齿轮按钮可收起 / 展开控制面板。

## 📁 项目结构

```
Threebody-3d/
├── index.html            # 页面结构与控制面板 DOM
├── main.js               # 核心逻辑：物理积分、渲染、镜头、UI 绑定
├── physics-worker.js     # Web Worker 物理计算（后台步进）
├── styles.css            # SpaceX 设计语言样式
├── vite.config.js        # Vite + singlefile 构建配置
├── wrangler.toml         # Cloudflare Pages 部署配置
├── public/  medres/      # 恒星贴图等静态资源
├── docs/                 # 设计 / 优化文档
└── DESIGN_SPEC.zh-CN.md  # 设计系统迁移规范（SpaceX 风格）
```

## 🔧 技术栈

- **Three.js** `0.160.0`（WebGL 渲染 / 后期泛光 / 轨道控制）
- **Vite** `^6` + `vite-plugin-singlefile`（单文件构建）
- **Web Worker**（物理仿真与主线程解耦）
- 自定义 GLSL 着色器（轨迹 / 节点）
